# Modern CRM Dashboard

A fully-featured, modern CRM dashboard built with React, Vite, Tailwind CSS, and Work Sans font.

## 🌐 Live Demo

**[🚀 Live Website](https://sales-pro-crm.vercel.app)**

**[📁 GitHub Repository](https://github.com/bamaniyamilan/SalesPro-CRM)**

## Features

### 🎯 Core Features
- Contact Management
- Deal Pipeline (Kanban Board)
- Task Management
- Activity Timeline
- Analytics Dashboard
- Calendar Integration
- Document Management
- Email Integration

### 🎨 UI Features
- Modern, clean design
- Fully responsive
- Dark mode ready
- Interactive charts
- Drag & drop interface
- Real-time notifications

### ⚙️ Technical Features
- Redux state management
- React Router navigation
- Reusable components
- TypeScript ready
- API integration ready
- Optimized performance
